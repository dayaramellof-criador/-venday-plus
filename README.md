# VENDAY+ v4
PWA de controle de vendas para iPhone.

Recursos:
- Dashboard
- Nova venda à vista/parcelada
- Parcelas individuais
- Clientes e histórico resumido
- Produtos com preço, custo e estoque
- Fluxo de caixa com entradas e saídas
- Relatório por período
- Top clientes, peças, vendido, recebido, a receber e lucro estimado
- Botão de cobrança via WhatsApp
- PWA com manifest, service worker e ícones

Publicação:
1. Hospede os arquivos em HTTPS.
2. Abra no Safari do iPhone.
3. Compartilhar → Adicionar à Tela de Início.

Os dados são locais ao navegador. Para backup/sincronização em nuvem, login e uso em vários aparelhos, conecte um backend/banco de dados.
